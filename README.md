# Designfriend

En kunnig vän som tittar in i ditt rum. Du visar rummet och det du gillar, pratar om hur det ska kännas, och får råd, idéskisser och till slut en plan du kan genomföra.

Webbapp på svenska för privatpersoner, byggd som sidoprojekt.

## Innehåll

| Sökväg | Vad |
|---|---|
| `AGENTS.md` | Instruktioner för kodagenter (Codex, Claude Code) |
| `docs/design.md` | Tjänstedesignen |
| `docs/samtal-exempel.md` | Ett påhittat samtal som förebild för tonen |
| `prompts/radgivaren.md` | Rådgivarens systemprompt |
| `evals/` | Testsvit för rådgivarens beteende |

## Kom igång med etapp 0

1. Skapa ett projekt i Claude-appen.
2. Klistra in allt under strecket i `prompts/radgivaren.md` som projektets instruktioner.
3. Lägg in moodboardbilder och ett foto av rummet som projektfiler.
4. Prata med vännen. Bedöm samtalet med `evals/kriterier.md`.
